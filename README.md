# Минский ТГ — тестовая версия
1. Создайте бота в BotFather, добавьте администратором канала с правом приглашать пользователей.
2. Узнайте числовой CHANNEL_ID (например через пересланное сообщение в собственный диагностический бот или API). Для теста желательно отдельный закрытый канал.
3. Загрузите файлы в отдельный GitHub репозиторий. Создайте Render PostgreSQL и Background Worker (Docker, ./Dockerfile, 1 instance, тот же регион, Auto Deploy off).
4. Environment: BOT_TOKEN, ADMIN_ID (числовой Telegram ID), CHANNEL_ID (отрицательный числовой ID), DATABASE_URL (internal URL), TESTER_IDS (ID тестировщиков через запятую). Не публикуйте секреты.
5. Deploy. /diagnostics, /admin, «Тест 5 минут», /start. Тестировщики должны быть в TESTER_IDS. Для проверки реферала второй аккаунт не должен быть подписан до регистрации. Используйте персональную ссылку из бота, а не общую ссылку канала.
6. Проверьте вступление, билеты, повторный /start, отписку, перезапуск, завершение, /results. Тестовые призы виртуальные. Удаление тестов не удаляет подписчиков.

Ограничения: это MVP для закрытого теста, реальный режим намеренно заблокирован. Нет реальной отправки Stars, публикации итогов, рассылок, CSV и редактора призов. Проверка рефералов при финальном выборе использует Telegram API; отображаемые билеты зависят от полученных событий. Старые подписчики могут участвовать, но не засчитываются как новые рефералы при регистрации. Повторная отправка тестового уведомления возможна при аварии между отправкой и записью статуса. Синтаксис проверен, интеграция с Telegram/PostgreSQL/Render не проверена. Перед публичным запуском требуется проверка законодательства и доработка боевого режима.
